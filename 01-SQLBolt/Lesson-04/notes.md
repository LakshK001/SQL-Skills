# Lesson 4

## Concepts Learned

- **DISTINCT** is used to get unique data of column.
- **ORDER BY** is used to sort the data according to columns .
- **LIMIT X** is used to display the top X records only.
- **OFFSET X** is used to skip the top X records only.

## Common Mistakes

- Forgetting **column name** while using **ORDER BY**.
- **OFFSET** can only be used after **LIMIT**.

## Key Takeaways

- Use **DISTINCT** at the start after **SELECT**.
- Always specify **ColumnName** after **ORDER BY**.
