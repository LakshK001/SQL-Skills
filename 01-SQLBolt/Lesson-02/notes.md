# Lesson 1

## Concepts Learned

- **WHERE** is used to apply condition while retrieval.
- **WHERE** can be used with multiple condition by OR/AND.
- **WHERE** uses various operators to apply condition.

## Common Mistakes

- Incomplete **analyzing** of the table schema.
- Incorrect use of **operators** in the WHERE clause.

## Key Takeaways

- **Operators** must be used according to conditions.
- **Analyze** table's schema carefully.

## Constraints for numbers
- Used for comparision and equality : **=, !=, <, <=, >, >=** 
- Used for numbers in range : **BETWEEN … AND …** 
- Used for numbers not in range : **NOT BETWEEN … AND …** 
- Number exist in a list : **IN (…)** 
- Number does not exist in a list : **NOT IN (…)**
