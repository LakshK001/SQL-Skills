# Lesson 3

## Concepts Learned

- **WHERE** uses with string and varchar.
- Learnt various **CONSTRAINTS** and their usecases.
- **WHERE** uses various operators to apply condition.

## Common Mistakes

- Initially **confused** with **% and _** usecase.
- Assuming data is also **case insensitive**.

## Key Takeaways

- **%** is used to match zero or more characters.
- **_** is used to match a single missing character only.
- **Syntax** is case **insensitive** but **data** is not.

## Constraints for numbers
- Used for comparision and equality : **=, !=** 
- Used for case sensitive string matching : **LIKE** 
- Used for case sensitive string matching : **NOT LIKE** 
- Strings exist in a list : **IN (…)** 
- Strings does not exist in a list : **NOT IN (…)**
